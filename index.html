Privacy Policy for Studio Assistant

Last updated: 08/12/2026

About this app

Studio Assistant is a personal, single-user tool created and used exclusively by the owner of Bewith Studio for managing and analyzing their own marketing content on Pinterest. This app is not distributed, shared, or made available to any other users, and no third party has access to it or the data it processes.

Questions about this policy can be sent to: bewithstudio21@gmail.com

What information the app accesses

Studio Assistant connects to my own Pinterest account and store to read and manage my own content through the Pinterest API. This includes:

  • My Pinterest profile information (username, account ID)
  • Boards and Pins I have created
  • Pin performance data (impressions, saves, clicks)
  • Analytics related to my Pinterest content

In addition to reading this information, the app may also create, update, or delete Pins on my own Pinterest store, at my direction and with my confirmation for each action.

The app only requests the minimum permissions ("scopes") needed to work, and it only ever acts on my own account — never on behalf of any other person.

Why this information is used

This data and functionality is used only to:

  • Display Pinterest content and performance inside the app
  • Help analyze and improve marketing and SEO strategy for my own Pinterest content
  • Generate reports or suggestions based on my existing content
  • Create, update, or delete Pins on my own Pinterest store, based on my own review and confirmation of each action

The data is not used for any purpose beyond what is described above, and no action is ever taken automatically without the owner reviewing and choosing it first.

How information is stored

  • In line with Pinterest's API policies, this app does not permanently store data pulled from the Pinterest API. Data is fetched fresh from Pinterest each time it is needed, used temporarily to generate reports or analysis, and not kept afterward.
  • The only exception is campaign analytics information about the owner's own account, which may be retained locally for the owner's own review — consistent with Pinterest's allowance for this data type.
  • Since this app has only one user (the owner), no data is ever shared with, sold to, or accessed by any other person or company.
  • Data is not used for advertising purposes.
  • Access tokens are kept private on the owner's device only.

Data retention

As described above, Pinterest data itself is not retained beyond the moment it's used to generate a report — it is re-fetched from the API each time. Only campaign analytics data about the owner's own account may be kept locally, and the owner may delete it at any time directly from the app or device.

Rights

As the sole user of this app, the owner can:

  • Disconnect Studio Assistant from their Pinterest account at any time through Pinterest's own account settings, which immediately stops all read and write access.
  • Access or delete any locally stored data (such as campaign analytics) at any time.
  • Review and approve every Pin creation, update, or deletion before it happens — the app does not take these actions automatically.

Changes to this policy

This privacy policy may be updated from time to time. Any changes will be posted on this page with an updated "Last updated" date.
